🚀 HOW TO USE

For End Users (No Technical Knowledge Needed):

1. DOWNLOAD:
   Option A: Download the ZIP:
   termchat-v1.2.0-cross-platform.zip (includes everything)
   
   Option B: Download single binary for your OS:
   - Linux: termchat-linux-amd64
   - macOS: termchat-macos-arm64 (Apple Silicon) or termchat-macos-amd64 (Intel)
   - Windows: termchat-windows-amd64.exe

2. EXTRACT (if using ZIP):
   unzip termchat-v1.2.0-cross-platform.zip
   cd termchat-v1.2.0-cross-platform

3. RUN:
   
   Linux/macOS:
   ./termchat.sh wss://termchat-relay.meetkhamar3501.workers.dev/ws
   
   Windows:
   termchat.bat
   (When prompted, paste the server URL)

4. CHAT:
   - Type your message at the bottom
   - See online users on the left
   - View chat history on the right
   - Press F1 for help
